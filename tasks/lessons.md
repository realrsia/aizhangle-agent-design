# Lessons

- When reviewing repository manifests, do not assume `provenance` or old source-package paths are still active dependencies. Treat them as possible migration/history references and verify whether the current repository has already absorbed the needed content before recommending that they remain.
- When repairing or generating mobile Figma pages, check whether the outer phone frame itself has Auto Layout. If it does, top-level structural zones such as status bar, top nav, scroll/content area, bottom bar, and modal sheets must use `layoutPositioning = ABSOLUTE`; otherwise the parent frame may reflow them and cause fixed chrome overlap.
- Do not assume increasing a card or content frame height fixes clipping. Inspect inner rows and text nodes too; stock rows, result-card body copy, and sheet descriptions often need their own height, `clipsContent = false`, and text height auto-resize.
- In modal trading states, hide or fully cover the underlying high-risk action fallback. A clipped pending trading button visible behind a sheet can look like an available ordinary action and should fail the checklist.
- For Figma generation tests, cloning from previously generated evaluation frames is not enough. The agent must probe/import/clone from the original confirmed component source or current design-system component instance, and must record source node/component key evidence before drawing.
- Do not treat dark visual resemblance as token compliance. If color variables/styles cannot be bound or verified, the output must be marked as low-fidelity/token pending, not reported as using the design system visual language.
- For partial components such as message-feed, fallback should be the minimum semantic gap only. Do not rebuild most of the page with custom cards and then claim component-first generation passed.
- Before editing Figma nodes, confirm the intended board by current selection, user-described spatial location, and frame name. If selection is unavailable, scan the canvas hierarchy and target the requested board explicitly; do not reuse stale node IDs from earlier tasks.
- When a component import is blocked by unavailable fonts, clone an existing correct linked instance, normalize editable text fonts only if needed, and reparent it into the target frame so screenshots include it. Page-root overlay clones do not count as a real repair.
