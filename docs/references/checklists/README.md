## Integration Rule

- For production-supported surfaces, use the JSON checklist directly.
- For AI archetypes, checklist JSON is not yet available; use `references/process/design-taster.md` and mark machine-readable checklist as missing.
- For chat fidelity pages, use the acceptance criteria in `references/fidelity/chat-fidelity-reconstruction.md` and mark checklist JSON as missing.
