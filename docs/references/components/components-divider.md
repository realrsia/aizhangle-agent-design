# Dividers

## Rule: Prefer sheet divider

Use `xzl/color/divider/sheet` as the primary divider color.

Why:
Sheet dividers match the product's mobile surface separation better than generic hard lines.

Verify:

- Major separators use `xzl/color/divider/sheet`.
- Other divider tokens are used only when a specific stronger or subtler hierarchy is needed.
- No arbitrary border color is used.
