# Anti-Patterns

Use these as review lenses and generation guardrails.

## Structural Anti-Patterns

- `tag_wall`: tags and capsules replace real market, account, or list hierarchy.
- `card_salad`: data is split into too many generic cards without a scan path.
- `agent_drift`: assistant controls become the page subject on a market/account page.
- `rank_drift`: market overview leaderboard modules stack vertically instead of compact horizontal slices.
- `required_zone_loss`: a required zone is removed and replaced with decoration or helper UI.

## Visual Anti-Patterns

- `theme_drift`: dark and light modes use different geometry instead of changed token roles.
- `type_drift`: text leaves the approved foundation type ramp.
- `icon_drift`: multiple icon families appear in one viewport without a confirmed reason.
- `color_semantic_drift`: red/green stop carrying financial movement semantics or blue stops carrying AI/action semantics.
- `neon_ai_overreach`: decorative AI glow becomes louder than financial information.

## Production Quality Anti-Patterns

- `lookalike_component`: a strong component is drawn from frames/shapes instead of a true Figma instance.
- `text_clipping`: labels, tabs, nav titles, tags, leaderboard titles, or data values are visibly clipped.
- `layout_drift`: text and values escape module bounds because Auto Layout or responsive structure is missing.
- `chart_drift`: production financial charts are approximated with arbitrary vector shapes.
- `safe_area_collision`: custom content collides with iOS safe area, Dynamic Island, or bottom dock.

## Preferred Corrections

- Remove before adding.
- Compress before restyling.
- Re-rank information before changing atmosphere.
- Restore component binding before polish.
- Restore text safety before visual tuning.
- Use chart-library output for real financial charts.
